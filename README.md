# 🛡️ 제2의 뇌 — 행동 가드레일 (개인 교정 버전)

**[기본 스타터킷](https://github.com/rubypapa/second-brain-starterkit)에 "AI 행동 강제" 한 겹을 더한 버전입니다.**
제작자(루비파파)가 실제로 자기 AI(Claude)를 교정하며 하드코딩한 규칙이에요.
기본 킷과 뭐가 다른지 보고, 원하면 이 hook만 얹으세요.

---

## 기본 킷 vs 이 버전 (뭐가 다른가)
| | 기본 스타터킷 | + 행동 가드레일 (이 repo) |
|---|---|---|
| **하는 일** | AI에게 **기억**을 준다 (색인·규칙·세션 hook) | 거기에 AI의 **행동**을 매 턴 강제한다 |
| **문제 해결** | AI가 까먹음 | AI가 **통보하고 박음 / 넘겨짚음 / 영합함 / 혼자 진행함** |
| **방식** | SessionStart hook (세션 시작 시 과거 통독) | **UserPromptSubmit hook** (매 사용자 턴마다 행동규칙 재주입) |
| **누가 쓰나** | AI 기억이 필요한 모두 | AI가 자꾸 앞서가거나 확인 없이 단정해서 답답한 사람 |

## 왜 hook인가
규칙을 `CLAUDE.md` 텍스트로만 두면 AI가 **자꾸 흘립니다**(몇 턴 지나면 무시). 그래서 **매 턴 기계로 재주입**합니다 — 기본 킷의 SessionStart hook와 같은 원리.

## 강제하는 규칙 (v1.1)
① 통보 금지 — 의도·계획을 선언하지 말고 그냥 하거나 물어라
② 진행방식(짧게/순서)을 AI가 정하지 말 것 — 정하는 건 사용자
③ 결과부터, 짧게 (보고서톤·볼드도배 금지)
④ 제안 ≠ 실행 — 합의 안 된 건 실행 전 물어라
⑤ hook로 매 턴 강제 (규칙 있어도 안 지킴을 기계 교정)
⑥ 넘겨짚기 금지 — 확인 안 한 원인을 훈련 패턴으로 즉시 단정 말고 검증부터

> 규칙 이력은 [CHANGELOG.md](CHANGELOG.md). 새 규칙 추가될 때마다 갱신됩니다.

## 설치 (2분)
1. `turn_guard.py` 를 당신 프로젝트의 `tools/` 에 넣기.
2. `.claude/settings.json` 의 `hooks` 안에 `settings.snippet.json` 의 `UserPromptSubmit` 블록 추가 (command 경로는 당신 파이썬·경로로).
3. Claude Code 재시작 → 이제 매 턴 이 규칙이 강제됩니다.
   (기본 킷을 먼저 깔았으면 그 위에 얹으면 됩니다.)

## ★규칙은 당신 것으로 바꾸세요
`turn_guard.py` 의 print 줄이 규칙입니다. AI가 당신을 답답하게 하는 행동이 있으면 **한 줄씩 추가**하세요. 이게 "당신 AI를 길들이는" 실제 방법입니다.
